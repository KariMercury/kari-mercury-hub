### Mission

To build a platform where wellness creators can thrive without compromising ethics, with built in transperency, true DEI enforcement, and community governance.

### Project Structure
- `database/` - SQL scripts and databasae schema
- `src/` - C# backend code
- `frontend/` - User interface (React)
- `docs/` - Documentation and transperency reports
- `tests/` - Code tests

### Ethical Commitments
1. **5% Maximum Platform Fee** - Hard-coded into database constraints 
2. **$100k Founder Income Cap** - Enforced at payment processing level
3. **Full Financial Transperency** - Every transaction publicly verifiable
4. **DEI-First Creator Verificatoin** - Mandatory accessibility and anti-hate standards

### Getting Started 
1. Run `database/01-schema.sql` to create your database
2. Open `src/` in Visual Studio
3. Run the application
